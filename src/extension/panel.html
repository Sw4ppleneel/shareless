Checking this site...

Check a message

Paste an email, SMS, WhatsApp or Instagram message. It's checked on this device. In Gmail, Google Messages and WhatsApp Web, ShareLess checks messages on screen by itself.

Share a file

Pick a document and where you're sending it. ShareLess works out what's in it and what that place actually needs, then makes a copy with only that.

Tip: you don't need to come here. Choose a file in any upload field and ShareLess offers to check it first.

What leaves this device

Messages, documents, form entries and policy text never leave. The on-device AI runs inside Chrome. The only network traffic is domain names sent for age checks (rdap.org) and a public phishing list being downloaded (nothing sent). All of it is listed here.
